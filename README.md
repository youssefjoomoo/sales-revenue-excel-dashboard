# 📊 Commercial Sales & Revenue Performance Dashboard

An interactive, multi-year sales performance and revenue analytics dashboard built entirely using **Microsoft Excel**. 

This dashboard covers historical commercial sales data from **2021 to 2024**, enabling business stakeholders to track revenue growth, evaluate regional performance, and measure key performance indicators (KPIs) with dynamic filtering.

## ✨ Key Features & Functionalities

* **⚡ Fully Dynamic & Flexible UI:** Designed with interactive **Slicers (Filter Buttons)** that allow users to instantly slice data by **Period (Years: 2021-2024)** and **Geographic Region (Central, East, South, West)**.
* **📈 Executive KPIs:** Real-time tracking of core business metrics:
  * **Total Revenue:** $2,756,640
  * **Total Quantity Sold:** 37,873 units
  * **Geographic Reach:** 531 Cities
  * **Plan Achievement Rate:** 92%
* **📅 Multi-Period & Seasonality Analysis:** Evaluates revenue distribution across years, quarters, and monthly trends (`Revenue by Month` & `Revenue by Quarter`).
* **📦 Product & Segment Breakdown:** Deep-dive analysis into customer segments and primary categories (*Technology*, *Office Supplies*, *Furniture*), along with subcategory sales shares.
* **🌍 Regional & City Benchmarking:** Regional revenue distribution paired with a ranking list of the **Top & Bottom Performing Cities**.

---

## 🛠️ Tools & Technologies Used

* **Core Tool:** Microsoft Excel
* **Techniques Applied:** Data Cleaning, Pivot Tables, Advanced Excel Formulas, Dynamic Charts, Slicers & Dynamic Filtering, Dark Theme UI/UX Design.

---

## 🚀 How to View the Project

1. Clone or download this repository.
2. Open the `.xlsx` file using Microsoft Excel.
3. Use the interactive slicer buttons at the top to filter data across different regions and years dynamically.
